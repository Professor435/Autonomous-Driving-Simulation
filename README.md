# Autonomous-Driving-Simulation

 The complete **NeuroDrive Autonomous Driving Simulation** has been saved as a single, self-contained HTML file.
 
---
 
## What's Inside — Complete Feature Set   
    
### 🧠 AI & Machine Learning 
- **Feedforward Neural Network** (9 → 6 → 4 architecture) 
- **Evolutionary Training** via mutation-based genetic algorithms
- **Real-time Neural Network Visualization** with animated neurons and weighted connections
- **Brain Persistence** — save/load best brains via localStorage

### 🚦 Simulation Environment
- **3-Lane Highway** with dashed lane markings and neon borders
- **Dynamic Traffic** (up to 50 vehicles) with randomized speeds and lanes
- **9-Ray LiDAR Sensor Array** with distance-based color coding (green/yellow/red)
- **Polygon Collision Detection** for accurate crash physics
- **Smooth Camera Following** with viewport translation

### 🎮 Three Simulation Modes
| Mode | Description |
|------|-------------|
| **Training** | Evolve 10–200 AI cars per generation |
| **Manual Drive** | Arrow key control for human driving |
| **Test Best** | Run the saved best neural network |

### 🎛️ Interactive Controls
- **Mutation Rate** slider (0–1)
- **Population Size** slider (10–200)
- **Traffic Density** slider (0–50)
- **Simulation Speed** multiplier (1x–10x)
- Toggle switches for sensors, NN viz, minimap, camera, debug

### 🎨 Visual Design
- **Cyberpunk dark theme** with cyan neon accents
- **Glowing car effects** and translucent traffic
- **Live sensor bar panel** with danger/warning/safe indicators
- **Mini map** showing all vehicles and the best car
- **Generation badge**, FPS counter, and performance stats
- **Animated overlay** between generations

### 📊 Real-time Metrics
- Generation counter
- Best fitness (distance traveled)
- Alive cars count
- Average speed (km/h)

---

## How to Use
1. Download the file
2. Open `neurodrive_simulation.html` in any modern browser
3. Click **Start Simulation** to begin training
4. Watch the AI learn to dodge traffic over generations
5. Save the best brain when satisfied, then test it in **Test Best** mode
